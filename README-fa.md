## 🔀 دو ترنسپورت

هر کاربر یکی از این سه حالت را می‌گیرد (در فرم ساخت یا در ویرایش):

| حالت | نتیجه در لینک اشتراک |
|---|---|
| 🔌 **WS + TLS** | فقط کانفیگ‌های `type=ws` |
| 🚀 **XHTTP + TLS** | فقط کانفیگ‌های `type=xhttp` (با `mode=packet-up`) |
| 🔀 **هر دو** | هر دو نوع، و برای هر Clean IP هم یکی از هر کدام |

اگر کاربری روی `ws` تنظیم شده باشد و با کانفیگ XHTTP وصل شود، اتصال رد می‌شود و برعکس.

### مسیرها

- WebSocket → `wss://<domain>/<WS_PATH>` (پیش‌فرض `/ws`)
- XHTTP → `https://<domain>/<XHTTP_PATH>/...` (پیش‌فرض `/xh`)

این دو مسیر باید با هم متفاوت باشند.

> ⚠️ **XHTTP آزمایشی است.** به حالت `packet-up` پیاده شده: uplink با POST های شماره‌دار
> و downlink با یک GET استریمی، به همراه بافر مرتب‌سازی برای چانک‌های نامرتب.
> اگر پروکسی یا CDN وسط راه پاسخ را بافر کند، downlink کند می‌شود یا قطع می‌شود.
> WS مسیر پایدارتری است — اگر به مشکل خوردی، کاربر را روی WS بگذار.

## 🚀 نصب روی Railway

**۱.** فایل‌های این پروژه را در یک ریپوی گیت‌هاب بگذار.

**۲.** برو [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → ریپوی خودت را انتخاب کن.

**۳.** تب **Variables** را باز کن و این‌ها را اضافه کن:

| متغیر | نمونه | لازم؟ |
|---|---|---|
| `SECRET_KEY` | یک رشته تصادفی بلند | ✅ |
| `DOMAIN` | `myapp.up.railway.app` | ✅ |
| `WS_PATH` | `ws` | اختیاری |
| `XHTTP_PATH` | `xh` | اختیاری |
| `DEVICE_WINDOW` | `300` | اختیاری |
| `SESSION_IDLE` | `90` | اختیاری |
| `DB_PATH` | `/tmp/panel.db` | اختیاری |
| `ADMIN_PASSWORD` | — | اختیاری (رد کردن صفحه Setup) |

**۴.** **Settings → Networking → Generate Domain** — دامنه‌ای که می‌دهد را در `DOMAIN` بگذار و یک بار Redeploy کن.

**۵.** برو `https://دامنه‌ات/` — صفحه Setup می‌آید، رمز بگذار، تمام.

دستور اجرا (برای همه پلتفرم‌ها):

```
gunicorn -k uvicorn.workers.UvicornWorker main:app --bind 0.0.0.0:$PORT --timeout 0
```

## 🧊 Clean IP

**تکی:** آدرس + برچسب → افزودن

**انبوه:** هر خط یک مورد، برچسب بعد از `#`:

```
104.16.132.229 # ایرانسل
172.67.72.14   # همراه اول
cdn.example.com # پشتیبان
188.114.97.3
```

هر Clean IP فعال به لینک اشتراک همه کاربران به عنوان کانفیگ اضافی اضافه می‌شود —
آدرس اتصال Clean IP می‌شود ولی `sni` و `host` روی دامنه اصلی می‌ماند.

با دکمه ⏸ می‌توانی یک آدرس را موقتاً غیرفعال کنی بدون اینکه حذفش کنی.

## 🔗 خروجی لینک اشتراک

```
📊 ali_home | 20.50GB | 22Days
🌐 ali_home · WS · Default
⚡ ali_home · Irancell · WS
🌐 ali_home · XHTTP · Default
⚡ ali_home · Irancell · XHTTP
```

خط اول یک **کانفیگ پوچ** است که نام کاربر، حجم باقی‌مانده و روز باقی‌مانده را در اسمش نشان می‌دهد.
روی پورت ۸۰ با `security=none` و مسیری است که هیچ‌کدام از inbound ها به آن گوش نمی‌دهند،
پس هیچ‌وقت واقعاً وصل نمی‌شود — فقط به عنوان یک برچسب بالای لیست کانفیگ‌های کاربر دیده می‌شود.

هدر `subscription-userinfo` هم ست می‌شود تا کلاینت‌هایی مثل Hiddify و Streisand
حجم و انقضا را در نوار خودشان هم نشان بدهند.

## 🔄 قطع کانفیگ لو رفته

پنل → مدیریت کاربران → **ویرایش**:

- دکمه **UUID جدید** → UUID تصادفی نو + پاک شدن لیست IP ها
- یا فیلد **UUID دستی** → هر UUID دلخواه

کانفیگ‌های قدیمی بلافاصله از کار می‌افتند. لینک اشتراک عوض نمی‌شود،
پس کاربر فقط باید Subscription خودش را Update کند.

## 📱 محدودیت دستگاه چطور کار می‌کند؟

هر IP مبدأ که به کانفیگ کاربر وصل می‌شود در جدول `user_ips` ثبت می‌شود
(همراه با پروتکل: ws یا xhttp) و تا `DEVICE_WINDOW` ثانیه پس از آخرین اتصال
«دستگاه فعال» شمرده می‌شود. اگر تعداد IP های فعال به سقف مجاز رسیده باشد،
اتصال از IP جدید رد می‌شود.

با دکمه **IP ها** لیست دقیق دستگاه‌های هر کاربر را با وضعیت آنلاین/آفلاین و پروتکل می‌بینی.

> چند دستگاه پشت یک روتر خانگی، یک IP مشترک دارند و یک دستگاه شمرده می‌شوند.
> این محدودیت ذاتی روش IP-based است.

## ⚠️ نکات مهم

- دیتابیس روی `/tmp` **موقت** است و با هر ریدیپلوی پاک می‌شود. برای نگه‌داری دائم،
  در Railway یک Volume بساز و `DB_PATH=/data/panel.db` بگذار.
- ارتقا از نسخه قبلی مشکلی ندارد — ستون‌های جدید (`transport` و `proto`) خودکار
  با `ALTER TABLE` اضافه می‌شوند.
- **UDP پشتیبانی نمی‌شود** (فقط TCP) — در کلاینت DNS را روی DoH بگذار.
- TLS توسط پلتفرم هاست انجام می‌شود؛ نیازی به نصب Xray core نیست.
- پهنای باند مصرفی را ارائه‌دهنده هاست از تو حساب می‌کند — حواست به صورت‌حساب باشد.
- این پروژه برای استفاده شخصی و آموزشی است.
